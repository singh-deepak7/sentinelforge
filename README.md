# SentinelForge

SentinelForge is an AI-powered production incident investigation and recovery agent built on TrueForge.

It investigates operational incidents using real tools, correlates evidence across logs, metrics, deployments, and source code, executes diagnostics in an isolated sandbox, and requires human approval before performing sensitive recovery actions.

## Hackathon

Built for the WeMakeDevs Agent Harness Hackathon using TrueForge.

## Core Principles

- Evidence before action
- Read operations are autonomous
- Sensitive write operations require approval
- Generated diagnostics run in an isolated sandbox
- Incident investigations remain traceable across sessions

## Planned Capabilities

- Incident Commander agent
- MCP-based observability tools
- Deployment investigation
- Source-code investigation
- Sandbox-based diagnostics
- Dynamic subagents
- Human approval gates
- Recovery verification
- Persistent incident sessions
